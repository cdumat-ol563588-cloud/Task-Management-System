# Task Management System Using Stack and Queue

## Project Description

The Task Management System Using Stack and Queue is a Java-based application designed to help users organize and manage their daily tasks efficiently.

The system allows users to add, view, complete, delete, search, and sort tasks. It uses different data structures and algorithms to demonstrate efficient task management.

## Features

- Add new tasks with descriptions, deadlines, and priorities
- View all tasks and their current status
- Process pending tasks using Queue (FIFO)
- Complete and delete tasks
- Undo previous actions using Stack (LIFO)
- Search tasks using Linear Search
- Sort tasks using Bubble Sort
- View pending tasks

## Data Structures and Algorithms

- **ArrayList:** Stores all task records.
- **Queue (FIFO):** Processes pending tasks in the order they were added.
- **Stack (LIFO):** Reverses the most recent action.
- **Linear Search:** Searches for tasks by ID or name.
- **Bubble Sort:** Sorts tasks by priority or deadline.

## Technologies Used

- Java
- Java Collections Framework
- Java Development Kit (JDK)

## How to Run the Project

1. Install the Java Development Kit (JDK).
2. Download or clone this GitHub repository.
3. Open the project folder in a terminal.
4. Compile the Java source code:

   ```bash
   javac src/TaskManagementSystem.java
   ```

5. Run the application:

   ```bash
   java -cp src TaskManagementSystem
   ```

6. Follow the menu instructions to manage your tasks.
